# 性能試験の事前予算

記録日: 2026-09-05。性能の計測前に固定。下記は合格実績ではない。

- 対象: PC / WebGL2 / 1920 × 1080 / devicePixelRatio 1 / six dynamic vehicles.
- 目標フレーム時間: p50 ≤ 16.7 ms、p95 ≤ 20 ms、p99 ≤ 33.3 ms。100 msを超える停止はロードを除き0回。
- 初期読み込み: 100 Mbps接続のウォームキャッシュで10秒以内。失敗はエラーと再試行ボタンを表示。
- CPU JSヒープ: 768 MiB以下、3周＋再レースを5回後の増加64 MiB以下。
- 通常走行・集団・同時爆発3回・近傍動的破片100・塗装200・区画境界を各60秒以上。3周反復を別計測。
- 同じ実データのステージを使用し、解像度・描画条件・commit・ブラウザー/GPU・OS・試験時間を出力する。
- ソフトウェアGPUやheadlessの値は参考値。対象GPUを同定し同条件で測定するまではAT-12をPASSにしない。

現在の実行環境はLinuxクラウド。ユーザー所有PCのGPUは未指定、実ゲームパッドは未接続。初見の人間評価・現地測量も未実施。
