# 実PLATEAUの岐阜ステージと6台カートレースを実装

空のリポジトリから、原資料の全53要件・受入IDを維持してMachiShiftを実装します。実都市の形状を使用し、破壊・局所塗装・車両物理が同じステージ状態を参照する構成です。

## 変更

- 岐阜市2024年度CityGMLの原典取得、座標変換、三角形化、DEMと詳細道路の切り分け、出典・権利台帳、gzip配信チャンク。
- 1.388 kmの実道路上で、Rapierによる6台3周、順序付きチェックポイント、順位、ドリフト、復帰、障害物迂回と破壊後の経路選択。
- 爆弾、局所ペイント、実在の設備・選定外壁の分離、破片上の塗装追従、8秒のグリップ効果、区画資源の実解放・復元とリセット。
- 独自のカート・画面・効果音、タイトル、体験導入、レース、自由走行、結果、再レース、キーボード・標準パッド対応。
- 実物理試験、原本・地理変換試験、型検査、配布ビルド、ブラウザーCIシナリオ、全要件台帳と受入記録。
