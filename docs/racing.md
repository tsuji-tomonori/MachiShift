# レースと車両の実装

`src/race.ts` は 1 単位 = 1 m、+Y 上、+Z 前方の Three.js / Rapier ワールドを受け取る。これはゲーム挙動の設計値であり、カートの実測性能や実在道路の精度を保証しない。

## 統合 API

```ts
const race = new Race(world, coursePoints, scene);
race.reset('race'); // または 'free'
// 固定 1/60 秒。ポーズやカウントダウンでは running = false。
race.update(1 / 60, input, position => environment.gripAt(position, race.elapsed), running);
world.step();
race.afterStep(1 / 60);
```

入力は `{ throttle, brake, steer, drift, recover }`。throttle は -1～1、brake は 0～1、steer は -1～1（正値は追従カメラから見て左）。`vehicles` はプレイヤー 1 台 + AI 5 台。自由走行はプレイヤーのみ物理・描画を有効にする。`player`、`elapsed`、`complete`、`allFinished`、`sampleRoute(distance)`、`driveAI(vehicle)`、`recover(vehicle = player)` を公開する。`driveAI(player)` は再現可能な自動入力試験にも使用できるが、人間の初見操作試験の代替ではない。

UI は `speed`（m/s、km/h 表示は ×3.6）、`lap`、`rank`、`checkpoint`、`boost`（残秒）、`driftCharge`、`grip`、`finished`、`finishTime` を参照する。ドリフトの視覚表現とブースト炎は付属の独自カートモデルに含む。音・入力機器・カメラ・投擲はホスト側で統合する。

## 物理と調整値

6 台とも Rapier の動的剛体で、180 kg のゲーム調整質量、角を丸めた衝突形状、CCD を持つ。通常走行は力積による前進・横滑り抑制と角速度制御で行う。AI が座標を毎フレーム指定する実装は使用しない。ピッチ・ロールは拘束し、アーケードとして横転を防ぐ。バンパーの接触、壁・破片からの力積は実際の物理ワールドで処理する。

最高速の初期値は 26 m/s、ブースト時は 34 m/s。加速力積は 13.5 m/s² 相当。ドリフト中は横グリップを減らし、操舵と速度条件を満たして蓄積したチャージを解除時の加速へ変換する。路面グリップ関数は自車・AI とも同じコントローラーで利用する。接地は自身を除いた下向きレイと面法線で判定する。

AI は実際の車両位置を経路へ投影し、速度に応じて 5～15 m 先を狙う。曲率・進行方向誤差で減速する。前方 3 本の障害物レイと左右の斜めレイを用い、他車・破片・壁を検出して操舵・制動する。小さな走行ライン差で並走・追い越しを可能にする。中心線上の固定障害物には、最大 25 m 先の経路レイと左右 5.2 m の通過レイを使う。空いている側へ減速しながら迂回し、障害物の 5 m 先までその側を維持する。この大きな横移動は局所的に直線の区間で用い、曲がり角では経路の曲がる方向と近距離レイで操舵する。元のコライダーが破壊で消えると中心線を選ぶため、近道利用に進行値の書き換えを必要としない。

障害物の前で 0.3 秒停止し、後方 3 m のレイが空いていれば、通常の車両制御で 0.9 秒の後退を行って車体を解放する。同じ場所で後退を繰り返さないよう、前進が 6 m に達する前に再び詰まった場合は安全な復帰へ移る。位置を移動させる復帰とは別の物理運転であり、逆方向のゲート通過に進行は付与しない。停止付近でも加速入力があれば角速度による操舵を残す。AI の自動経路追従は通常グリップで行う。柵の近くで自動ドリフトを始めると外側へ滑り続けたため、プレイヤーのドリフト入力と区別した制御方針とした。車両物理・ペイントのグリップ規則は同一である。

先着車は通常の物理走行を続け、停止車でゴールを塞がない。全員の順位・完走時間は確定後に更新しない。

## 周回、順位、復帰

経路頂点を順序付きのゲートとして扱う。前フレームから現在までの区間がゲート平面を順方向に横切り、ゲート中心から横方向 8 m 以内・高さ 2.2 m 以内の場合にのみ次へ進む。逆走、別のゲート、遠方のゲート延長線、1 フレーム 70 m/s 相当を超える大きな飛躍では進まない。周回は最後のゲートからスタートへ戻ったときだけ加算し、3 周で完走する。順位の未完走部分は最後に通ったゲートから次のゲートへの有界な射影とする。

復帰だけは明示的な再配置である。最後に通ったゲートより前の経路位置を候補とし、下向きレイによる固定地面の確認、斜面法線、実寸以上の車両形状での重なり検査を行う。安全な候補がなければ再配置を拒否する。周回・次ゲートは保持して進めない。落下・2.25 秒の加速中スタック、および AI の 2 秒の逆走で復帰を試みる。未通過ゲートを 6 m 以上過ぎた状態が 1.2 秒続いた場合も、未通過分を付与せず直前へ戻す。通常は最後の通過点より 3 m 手前、停止状態からの復帰は障害物を回り込む助走が必要なため 22 m 手前を最初の候補とする。手動の復帰入力にも対応する。これらの閾値を設定しただけで「実コースで必ず 3 秒以内」を保証したとは扱わない。

## 実施した検証と残る範囲

`tests/race.test.ts` の検証対象は順序付き 3 周、逆走・ゲート省略・遠方交差・大きな座標飛躍の拒否、復帰の進行維持、動的 6 台とモード切替、カウントダウン停止、実際の壁接触、ドリフト加速とグリップ適用、安全な復帰、惰性での順方向走行を誤って復帰させず持続的な逆走だけを検出すること、未通過ゲートの故障注入から 3 秒以内の復帰、開通前後の経路長・時間差、6 台全車の動的 3 周完走。

最後の試験は楕円の人工経路と平面コライダーを明示的な fixture とし、全車を実際のコントローラーと物理ステップで完走させる。テスト用に周回や位置を書き換えて完走させない。復帰なし・全 72 ゲート・3 周の完走も検査する。ログの `SYNTHETIC_OVAL_PHYSICS` に距離、完走秒数、復帰回数を記録する。この結果を実在ステージの完走可能性、性能試験、初見プレイ評価の合格には転用しない。

中心線の幅 7 m の人工障害物を使う比較試験では、未破壊時 75.537 m / 4.717 秒、破壊後 74.372 m / 4.217 秒で同じ終点へ到達した。どちらも復帰 0 回。迂回時の横方向最大距離は 7.430 m。これは人工直線でのコントローラー試験であり、実在道路の新設・拡幅や実車計測ではない。

`tests/real-stage.test.ts` は `stage.json` と全配信区画の元メッシュを読み、同じ Environment / Rapier のコライダーを作る。実在道路の高さを保った 1,388.202 m の経路に、UI と同じ距離 72 m・全長の 31%・62% の 3 か所に横位置 4.5 m の柵と、距離 115 m の中央ゲートを加える。全車 3 周を、通常状態と実際に柵を破壊した状態でそれぞれ実行する。実行時の stage SHA-256、全車の完走時刻、通過ゲート数、完走までの復帰数、復帰直前の位置・合法な通過距離・周回・車両番号、30 秒ごとの位置を `artifacts/real-stage-physics.json` に出力する。描画なしの自動入力物理試験であり、人間の操作評価や GPU 性能の証拠ではない。

同じ実データの道路上で距離 70～155 m の区間をプレイヤー車両の自動入力で走る別試験では、中央ゲートを破壊した場合の物理走行距離・時間が短くなり、どちらも区間内の復帰が 0 回であることを検査する。72 m の横位置の柵は両条件で同じ状態にする。元の道の高さ・幅と順路は変えない。実測値と使用 stage の SHA-256 は `artifacts/real-shortcut-physics.json` に残す。

全車完走試験は、各車が 3 周と 1,134 個の順序付きゲートを実際に通過すること、および異なる確定順位を得ることを検査する。復帰によって未通過ゲートを付与しない。最新実行の通常状態・柵破壊後の完走秒数と復帰数は `artifacts/real-stage-physics.json` に車両ごとに記録する。

最終調査では、旧配置の距離 32 m の柵が最初の曲がり角で車両を押さえ込み、後続車両の復帰が 18 回に達する不具合を、実際の Rapier 接触マニフォールドまで追跡した。衝突相手は元データの構造物ではなく、`game_added` の `game:fence:32` の 3 部品だった。接触法線・車両位置・コライダーとオブジェクトの対応は `artifacts/first-bend-contact-diagnosis-before-relocation.json` に保存した。ゲームで追加したこの柵を曲率の小さい距離 72 m へ移し、元の道路・地形・建物・115 m の中央ゲートを変更せずに、曲がり角の押さえ込みを解消した。再発を隠さないため、全 3 周で各車の最初の曲がり角の復帰が 1 周内で繰り返されないことを内部回帰試験として追加した。移設後の接触観測は `artifacts/first-bend-contact-diagnosis.json` に残す。

別の小さな修正として、車両の前方単位ベクトルを力積計算で破壊的に変更しないようにした。減速力の符号や大きさを逆走方向と取り違えないためで、車両に与える力積は同じである。惰性走行の物理試験で旧コードの誤復帰を再現してから修正し、順方向は復帰せず、持続的な逆走だけが復帰することを確認した。

これらは描画なしの自動入力と故障注入の検証である。復帰を伴う交通状況は残り、全車の完走経路があることと、滑らかで楽しい運転体験の検証は区別する。GAME-06 の品質完成や全条件での 3 秒以内復帰を主張しない。

採用経路は source_only の道路面との対応を検査したもので、現地測量済みではない。道路境界までの最小距離 9.360 m に対し、ゲートの横許容 8 m とカート半幅 0.73 m はその内側に収まる。キーボード / 実ゲームパッドと音・カメラの体験、指定ケース全体での 3 秒以内復帰、1080p の対象実機性能は統合側で別途検証する。
