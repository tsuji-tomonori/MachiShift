# MachiShift（マチシフト）

岐阜駅北口周辺の公開都市データを使い、爆弾とペイントで街に作用するブラウザー用カートレースを制作しています。プレイヤー1台＋AI5台、3周レースと自由走行が対象です。

**ビルド生成・物理検証済み／3Dプレイの受入未完了。** 実在データ、走行・破壊・塗装の物理実装と配布ビルドを作成しました。Workの検証ブラウザーはWebGLが無効で、実際に3D画面を操作するプレイ確認はできていません。実行結果と未達は [受入記録](docs/acceptance.md)、全53原要件・受入IDと追加管理要件は [要件台帳](docs/requirements-ledger.json) に保持しています。

クリーン依存導入・型検査・31件の自動試験・ビルドに成功しました。原典の同じ道路上で、6動的車両が柵の破壊前後の両方を3周し、各1134の順序付きチェックポイントを通過しています。独立した地理監査5件と取得原本17件のハッシュ確認も成功しました。ブラウザーE2Eは2件を用意し、実行は未完了です。

## 起動

Node.js 22.12以降または24とnpmを使用します。この作業ではNode.js 24.19.0で検証しました。依存バージョンは `package-lock.json` に固定します。

```sh
npm ci
npm run dev
```

ブラウザーで `http://localhost:4173` を開きます。WebGL2対応PCブラウザーが対象です。実ゲームパッドの検証は別途必要です。

## 検査・ビルド

```sh
npm run typecheck
npm test
node scripts/check-requirements.mjs
npm run build
npm run preview
```

上記のクリーン導入からの検査と証跡保存をまとめて再現するには `python scripts/verify-release.py` を使います。E2Eの検出と実ブラウザー実行は分けて記録します。

生成物は `dist/` です。HTTPサーバーで配信します。`file://` での直接起動には対応しません。GitHub Actionsにはビルド・検査記録・ブラウザーE2EをArtifactsへ保存する設定を用意しましたが、初回CIで型検査・31物理試験・ビルドが成功しました。圧縮データ読込の修正後は36件のテストと通信再試行E2Eが成功し、練習スキップの修正と完走・再レースのE2Eを進めています。自動マージ・本番公開も行っていません。

`check-requirements` は原文の保存、全ID、証跡と状態の整合性を検査します。CIの成功は全受入要件の合格を意味しません。全必須要件の合格を要求するには次を実行します。

```sh
node scripts/check-requirements.mjs --require-acceptance
```

ブラウザーE2Eはビルド後に `npx playwright install --with-deps chromium` と `npx playwright test` で実行します。実データと実際のキー入力・車両物理を利用し、CI上のソフトウェア描画で機能を確認します。結果は `reports/` とCI Artifactsに残ります。対象GPUの1080p性能試験や人の初見評価とは別条件です。

## データと制約

原資料は [source_materials](source_materials/) に変更せず保存しています。巨大な原典ZIPをGitやゲーム配信物に含めず、採用区域の加工データを利用します。取得・再生成の実行方法と出典は [地理データ記録](docs/geodata.md)、実装中の契約は [データ契約](docs/data-contract.md) を参照してください。

地理は公開データ由来で、未測量部分を実測済みとは扱いません。現在のAOI選択矩形は0.5184km²、コースは1,388.202mです。約0.3〜0.5km²という範囲目標と最終境界の確定は別途残しています。道路端±30cm、段差・相対高さ±5〜10cm、建物±1m、実機1080p/60fpsは未検証です。テクスチャと近景照合、個別の彫刻等の権利確認も未完了です。ゲーム専用の仮設物は `game_added` として識別します。実在する施設・自治体の公式作品ではありません。

現在の区画配信はJSON gzipです。原文の「GLB等」に対する可逆な形式選択で、テクスチャ採用と実配信性能の計測はPERF-04に残しています。独自コード、同梱ライブラリ、地理データの条件は分けて扱い、配布物にも `THIRD-PARTY-NOTICES.txt` を同梱しています。

今後の作業と判断は [ロードマップ](docs/roadmap.md)、性能の事前予算は [性能予算](docs/performance-budget.md) に記録しています。

画面が重い場合はタイトルの「描画を軽量にする」を選んでください。3D解像度を縦横半分にし、影を省きます。街の形状、当たり判定、台数やレース進行は変わりません。「描画を高品質にする」で戻せます。
