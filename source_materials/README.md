# リアルカート 企画・調査資料 v0.1

- requirements.md: 候補地比較、素材収集、地理精度、レース、破壊、塗装、性能、受入試験の要件案。
- sources.json: 出典URL、確認状態、未確認事項、岐阜市の配布ファイルURL。
- asset_manifest_template.csv: 今後取得する素材の出典・精度・許諾台帳の空テンプレート。

本パッケージは調査と仕様案です。実際の都市モデル、現地写真、ゲーム実装は含みません。数値目標と第一候補は提案であり、データインポート・現地測量・性能測定の結果ではありません。

公開年/版名、元資料の測量・撮影年、形式変換日、取得日を分けて管理してください。確認日: 2026-09-05。
